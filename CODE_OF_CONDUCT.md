# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text at that link is the project's code of conduct.

## In short

- Be respectful and welcoming. Disagree about ideas, not people.
- No harassment, insults, discriminatory language, sexualised content, or
  publishing others' private information.
- Assume good faith, accept constructive criticism, and focus on what is best for
  the project and its users.

These standards apply in all project spaces (issues, pull requests, discussions,
and reviews) and when representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@shawnazar](https://github.com/shawnazar),
using GitHub's private reporting:
<https://github.com/shawnazar/overtime/security/advisories/new>. Mark the report as a
Code of Conduct matter rather than a vulnerability. You can also use GitHub's
[report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature for content on the site.

All reports are reviewed promptly and kept confidential. The maintainer will act
according to the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines),
from a private warning up to a permanent ban.
